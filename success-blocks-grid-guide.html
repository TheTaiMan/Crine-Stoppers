CSS Classes Reference

Grid Container Classes

/* Grid Layouts */ .grid-1-col → Single column .grid-2-col → Two columns .grid-3-col → Three columns .grid-4-col → Four columns .grid-5-col → Five columns .grid-auto-fit → Responsive auto-fit (recommended) .grid-auto-fill → Responsive auto-fill /* Advanced Grids */ .grid-asymmetric → 2fr 1fr 1fr layout .grid-mixed → 6-column with span classes

Card Classes

/* Card Structure */ .success-card → Main card container .success-card-header → Large number/text (25px, bold) .success-card-body → Description text (18px, regular) .success-card-icon → Icon container (84x76px) /* Card Modifiers */ .is-reversed → Reverses card content order .is-mobile → Mobile-optimized sizing /* Grid Span Classes (for .grid-mixed) */ .span-2 → Takes up 2 grid columns .span-3 → Takes up 3 grid columns
