# Winnipeg Crime Stoppers Redesign

A modern redesign of the Winnipeg Crime Stoppers website, originally created for a design competition. This project focuses on delivering a clean, accessible, and responsive user interface to better serve the community.

## Features

* Responsive layout optimized for both desktop and mobile devices.
* Intuitive navigation designed for quickly submitting tips and accessing community resources.
* Lightweight frontend architecture ensuring fast load times.

## Technologies Used

* HTML5
* CSS3
* Skeleton.css
* JavaScript

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You only need a modern web browser to view and interact with the application.

### Installation

1. Clone the repository to your local machine:
   ```sh
   git clone https://github.com/TheTaiMan/Crine-Stoppers.git
   ```
2. Navigate to the project directory:
   
```sh
   cd Crine-Stoppers
   ```
3. Open `index.html` in your web browser to view the site. 

## Project Background

This repository contains the frontend codebase developed as a submission for the design competition aimed at revamping the digital presence of the Winnipeg Crime Stoppers initiative. The design relies on Skeleton.css to maintain a lightweight and highly responsive structure without the overhead of larger utility frameworks.
